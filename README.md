# CodeAlpha Hangman Game

A simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features

- Randomly selects a word from a predefined list.
- Allows the player to guess one letter at a time.
- Displays correctly guessed letters.
- Allows a maximum of 6 incorrect guesses.
- Prevents repeated guesses.
- Validates user input.
- Displays win or loss messages.

## Technologies Used

- Python
- Random module

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run `hangman.py`.
4. Enter one letter at a time when prompted.

## Game Rules

- Guess the hidden word one letter at a time.
- A correct guess reveals the letter.
- An incorrect guess increases the incorrect guess count.
- The player loses after 6 incorrect guesses.
- The player wins when all letters are revealed.
